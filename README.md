# Best Rent Fleet Calendar – app updates

This repository holds the published versions of the **Best Rent Fleet Calendar** Android app.

The app checks the latest release here (Settings → App updates) and offers the download when a newer version exists.

- Each release has one file: `Best-Rent-Fleet-Calendar-x.y.z.apk`.
- The app in the releases is the clean edition: it contains no cars, bookings or client details.
- Installing a newer version over an older one keeps the data already on the phone.
