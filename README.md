# Best Rent Fleet Calendar – app updates

This repository holds the current published version of the **Best Rent Fleet Calendar** Android app.

The app reads `latest.json` here (Settings → App updates) and offers the download when a newer version exists.

- `latest.json` names the current version and its download link.
- `Best-Rent-Fleet-Calendar-x.y.z.apk` is the clean edition: it contains no cars, bookings or client details.
- Installing a newer version over an older one keeps the data already on the phone.
